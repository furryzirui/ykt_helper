# iOS 后台运行

提供静音音频、画中画、持续定位三种方案，默认静音音频。开启服务、启用自动启动或更改方案时需确认限制；已确认的同一方案可自动启动。定位方案可先保存，实际开启前需“始终允许”。设备坐标不会保存、上传或用于课堂签到。

每次实际启动新的系统服务，定时设置恢复为“永不”。开启自动启动服务时固定为“永不”，需先关闭自动启动服务，才能选择 10 分钟、2 小时或 24 小时并显示倒计时。重复刷新与返回前台不重置当前倒计时。到期处于前台时只停保活，处于后台时停止保活和自动化，让系统挂起应用。

静音音频允许混音，不设置系统“正在播放”信息；来电、Siri、其他应用独占音频等仍可中断。画中画显示时钟，关闭或暂停浮窗会停服。持续定位可能增加耗电，定位权限撤销或系统暂停定位会影响运行。强行关闭、系统回收、重启及网络中断都可能阻止自动化。

用户已完成三种方案的设备测试；正式版已移除临时每 10 秒诊断日志。后台资源存在不保证后续持续运行，需以实际课堂连接、签到和答题结果为准。

## 检查步骤

1. 自行签名安装 iOS 15+ IPA，保留 audio、location 后台声明及定位用途说明。登录后选择方案，确认提示并开启。
2. 分别检查静音音频、画中画和持续定位；拒绝定位、关闭浮窗或发生系统中断后，开关和错误原因应同步实际状态。
3. 锁屏或切换应用，检查真实课堂连接、自动签到、题目填充及延迟提交。来电、其他媒体播放、断网重连、撤销权限分别测试。
4. 关闭自动启动服务后手动设定定时，核对前后台到期规则；再次启动系统服务应恢复永不，刷新不得重置本次手动设置的倒计时。重新启用自动启动服务应取消倒计时，固定永不。

iOS 不支持应用开机自启动；后台被系统终止后不能保证恢复。安装包不包含长任务或依赖 Bundle ID 的后台任务白名单，重签时无需为后台方案额外修改任务标识。
