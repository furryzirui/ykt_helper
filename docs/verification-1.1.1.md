# 1.1.1 测试记录

版本：1.1.1+17；待用户验收，未发布 Release。稳定版仍为 1.1。

检查范围：手机课件与题目边界、教师当前页标识、跨设备本人答案、课堂中途开启自动答题，以及原有自动提交队列与后台提醒。

## 修复核对

- 手机端课件和题卡共用外层边框，以分隔线区分；缩放课件不覆盖题目。教师当前页独立于用户正在浏览的页，关闭跟随后仍保留标识。
- 题卡订阅控制器的草稿变化，自定义 AI 异步返回后立即更新选项；不覆盖用户已经修改的答案。已覆盖同一题卡实例及父页面同时重建两种情况。
- 官方实时课堂前端直接从带课堂凭证的 `lesson/presentation/fetch` 读取 `problem.result`。原实现误用课后摘要，现将实时同步和自动提交前复查统一改用实时数据；历史课堂保留课后接口。本人答案与标准答案分开处理，数据缺失或格式异常仍显示未知。

## 自动检查

- 全部 508 项 Flutter 测试通过，静态分析无问题。
- 覆盖实时本人答案与标准答案隔离、未批分答案、空结果语义、凭证与课堂归属检查、跨设备提交前复查、异步 AI 草稿刷新、人工编辑保护，以及原有自动化、账号隔离和后台通知。
- 已检查手机布局截图，并以缩放后的实际绘制像素确认课件不覆盖题卡。

本轮不操作设备；实时接口的本地测试使用按官方前端编写的模拟响应，跨设备真实课堂行为仍由用户验收。
