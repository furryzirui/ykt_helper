# 0.1.2

版本：0.1.2+3；日期：2026-11-14。

- 课堂回顾合并到详情页，直接位于签到信息分隔线下；右上角下载取代刷新按钮，刷新改为下拉操作。
- 课件按图片实际比例显示，移除固定 4:3 容器产生的留白，缩小页码与保存按钮；已有答案继续显示。
- 单页和全部图片直接保存到系统相册的 `Pictures/雨课堂`。按页下载并保存，避免批量保留完整课件图片；失败显示已保存页数。
- ZIP 与完整 PPTX 导出后仍使用分享面板，“回顾 PPTX”更名为“完整 PPTX”。动态课堂使用相同的图片保存方式。
- 标题回到导航栏，长标题省略，长按查看完整内容。
- 采用青色强调、浅色卡片、细边框和统一圆角，提供对应深色样式，不增加装饰说明。
- “自动进入课堂”改为“自动签到”，沿用同一设置；后台正常提示隐藏，仅显示真实异常。
- 新增应用权限页，读取相机、通知、相册保存、电池优化状态；说明用途和系统步骤，确认后才跳转。返回系统设置后重新读取，回到应用设置后重试后台服务。
- Android 10+ 写相册不申请读取权限；Android 8–9 使用存储授权。后台启动先检查权限，并禁用依赖库的自动电池授权弹窗。
- 修正后台插件的通知等级映射，使用实际 LOW 级别的静默通知；既有关闭的通知类别需由用户在系统中开启，不重建频道绕过用户选择。

本轮不使用 ADB、不安装或操作手机。静态分析、120 项本地测试及离线截图已通过；原生相册实际可见性、系统权限页面和真实后台行为由用户自行测试。完整清单见 [Android 联调](android-validation.md)。
