# 1.0.1 验证

版本：1.0.1+6；日期：2026-11-14；状态：等待用户验收，未发布 Release。

- 本地 203 项 Flutter 测试通过，静态分析无问题。覆盖服务启停、手动关闭后的防重启、设置保存、横屏分栏、选页与答案草稿保留，以及启动提示、完整性签名和文件变化检查。
- 手机 360×800、窄横屏 800×400、平板 1024×768、桌面 1280×800 及字号 1.0 / 1.5 进行了离线布局验证；设置项卡片宽度及备注检查通过。
- Android 正式签名构建通过，包名与 1.0.1+6、最低 API 26、三种 ABI、发布证书和 APK v2 签名均已核验。
- [Windows / iOS 云端构建](https://github.com/furryzirui/ykt_helper/actions/runs/43587633372) 通过。Windows 为每用户 x64 安装包；iOS 为 iOS 15+ arm64 未签名 IPA，需自行签名。
- [Android 云端检查](https://github.com/furryzirui/ykt_helper/actions/runs/43587740182) 的分析与测试通过；正式交付使用本地正式签名 APK，CI 测试包不替代正式包。

Android 核对已安装应用的发布证书。Windows / iOS 核对带 Ed25519 签名的文件清单及其摘要；iOS 对代码采用忽略正常重签元数据的摘要，并排除可被重签修改的签名目录、描述文件和 Info.plist。此检查用于发现发布身份或受校验文件不一致，不证明程序无法被逆向修改。

本轮未安装或操作目标设备，不含真实账号、课堂或长时间后台运行验收。构建来源、文件大小与 SHA-256 随验收包的 BUILD-INFO / SHA256SUMS 提供。验收前不创建 1.0.1 标签或发布 Release。
