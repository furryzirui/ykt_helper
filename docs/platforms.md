# 平台支持

版本 1.1.0+16，仅适配普通版雨课堂 `www.yuketang.cn`。

| 平台 | 标识 | 要求与产物 |
| --- | --- | --- |
| Android | `com.furryzirui.ykt_helper` | Android 8.0+；独立发布签名 APK，提供 arm64-v8a 与 universal（三种 ABI） |
| Windows | `ykt_helper` | Windows 10 1809+ x64；每用户 EXE 安装包，无需管理员权限 |
| iOS | `com.furryzirui.ykt-helper` | iOS 15+ arm64；主应用未签名 IPA，安装前需自行签名 |

课程、历史课堂、签到、答案同步、AI、自动化设置、日志及课件导出共用 Dart 实现。目标平台构建结果和实际测试边界见 [验证记录](verification-1.1.md)。

| 功能 | Android | Windows | iOS |
| --- | --- | --- | --- |
| 登录安全验证 | 系统 WebView | WebView2；缺少运行时提供官方下载入口 | 系统 WebView |
| 二维码入课 | 相机扫描或输入链接 | 输入二维码链接 | 相机扫描或输入链接 |
| 图片保存 | 系统相册 | 选择文件夹保存 | Photos 相册，仅申请新增图片权限 |
| ZIP / PPTX / 日志导出 | 系统分享 | 文件保存框 | 系统分享，包含 iPad 弹出位置 |
| 权限管理 | 相机、通知、相册、电池与厂商自启动管理；位置签到无需设备定位 | 相机暂不支持；自启动可检查与设置；文件保存、定位无需额外授权 | 相机、通知、相册新增权限，持续定位方案需始终允许定位 |
| 自动化运行 | 前台服务及通知，仍受厂商后台策略影响 | 应用进程运行期间；关闭或系统休眠会中断 | 静音音频、画中画、持续定位后台方案，仍受系统中断和资源限制 |
| 课堂提醒 | 独立“课堂提醒”通知类别 | 托盘气泡提醒 | 已授权的本地通知 |

申请权限前先显示用途、操作步骤并等待确认。相机、通知优先调用单项授权；已拒绝或不能直接申请时进入本应用设置。Android 电池管理统一进入单应用详情，不按当前优化状态切换到不同应用列表。

自动签到包含位置签到，开启时确认使用服务器签到中心，手动位置签到逐次确认。课堂提醒仅在后台且应用实际运行时触发，受系统通知设置影响；Windows 气泡不保证保留在通知中心。

Android 发布证书、密码及本机配置不进入源码包。Windows 安装包未进行 Authenticode 签名。iOS 使用 `--no-codesign` 构建，主应用无签名和描述文件，框架可能保留工具链签名；设备安装需要对完整应用自行重签。
