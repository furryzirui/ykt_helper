# 1.1 测试记录

版本：1.1.0+16；状态：待验收，未发布 Release；稳定版仍为 1.0.3。

## 检查范围

- 题目读取后预生成答案，未开放时可编辑但不能提交；开放后开始延迟计时，提交使用最新草稿。同一课堂按教师布置顺序排队，同批按课件页码；每题取布置后延迟与上一题提交成功后间隔中较晚的时间，间隔沿用提交延迟设置。
- 已提交、教师结束及限时到期状态优先显示，不残留填充或确认时间提示。
- 位置自动签到需独立开启并确认，每轮去重；手动位置签到仍每次确认，已核实的位置签到可补足延迟的报告状态。
- 实时与历史课件按页面展示题目；历史入口识别上课中课堂并转入动态；教师翻页时定位对应预览，手动滑动不锁定。

- 开启自动提交需二次确认；同课堂手动提交成功也会推迟后续自动提交，手动提交本身不受自动队列限制。AI 失败跳过，提交结果不明则等待同步且不盲目重试。新发现的远端记录缺少提交时间时，从本机首次确认时刻保守计时，重复同步不续延。
- 后台本地提醒覆盖手动作答、草稿待提交与自动处理失败；未开放、前台、已提交或已结束不提醒，同一题同一情况去重。提醒使用现有通知授权，不自动申请权限；Android 独立“课堂提醒”分类，点击打开应用。

静态分析无问题，486 项 Flutter 测试全部通过，包含账号隔离、迟到 AI 结果、空草稿不提交、逐题间隔、时限恢复、位置轮次、提醒去重和窄屏/横屏回归。Windows 提醒相关 C++ 仅完成 MSVC 单文件编译，iOS 通知仅静态复核；本轮不构建 Windows/iOS，不安装或操作设备，由用户验证真实课堂与系统通知行为。
