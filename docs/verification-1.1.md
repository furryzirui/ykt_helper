# 1.1 测试记录

版本：1.1.0+16；状态：待验收，未发布 Release；稳定版仍为 1.0.3。

## 检查范围

- 题目读取后预生成答案，未开放时可编辑但不能提交；开放后开始延迟计时，提交使用最新草稿。
- 已提交、教师结束及限时到期状态优先显示，不残留填充或确认时间提示。
- 位置自动签到需独立开启并确认，每轮去重；手动位置签到仍每次确认，已核实的位置签到可补足延迟的报告状态。
- 实时与历史课件按页面展示题目；历史入口识别上课中课堂并转入动态；教师翻页时定位对应预览，手动滑动不锁定。

静态分析无问题，460 项 Flutter 测试全部通过，包含账号隔离、迟到 AI 结果、空草稿不提交、时限恢复、位置轮次和窄屏/横屏回归。本轮不安装或操作设备，由用户验证真实课堂与服务端行为。
