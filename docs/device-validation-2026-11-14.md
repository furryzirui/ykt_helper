# Android 真机验收记录

日期：2026-11-14；版本：0.1.1+2；包名：`com.furryzirui.rain_classroom`。

设备为 Android 16 / API 36，1440×3200，支持 root。本轮经用户授权使用 ADB 覆盖安装和操作已登录应用。没有修改生产代码，APK 与已交付的 0.1.1 文件一致，无需重新构建。

## 已观察结果

| 项目 | 真机结果 | 验证边界 |
| --- | --- | --- |
| 安装与冷启动 | 覆盖安装成功；原账号登录态恢复；强制停止后重开仍已登录 | 未重新执行二维码、密码或短信登录，未退出账号 |
| 课程与历史列表 | 真实账号显示 2 门课程；历史课堂列表及详情可加载 | 未与官方端逐门对照全部在读、归档课程和跨页总数 |
| 本节签到 | 历史课堂详情显示“已签到” | 仅读取已有状态；未执行入课签到或位置签到 |
| 回顾入口 | 历史详情仅一个“课堂回顾”入口；无重复课件或回放入口 | 旧版课堂详情未真机测试 |
| 历史答案 | 一次回顾显示 32 页、7 道已有作答记录；实际题目下显示“我的答案 · 已提交”、答案正文及“待批改” | 未覆盖进行中课堂的答案同步、零分和所有题型 |
| 回顾图片与单页下载 | 课件图片加载；单页图片导出到系统分享面板；图片解码校验通过，1280×720，70,985 字节 | 未点击外部分享目标 |
| 全部图片 ZIP | 导出到系统分享面板；2,345,377 字节，32 张图片，无重名，ZIP CRC 通过 | 本轮在内存校验，不保留电脑课件副本 |
| 图片版 PPTX | 导出到系统分享面板；2,380,713 字节，32 个 slide XML、32 个媒体文件，ZIP CRC 通过 | 未用 PowerPoint/WPS 渲染验收 |
| AI 模型列表 | 将手机内旧服务地址换成用户明确提供的地址后，刷新成功显示多个真实模型；原模型仍可选择；设置保存成功 | 保留原密钥，未读取或修改其内容；未调用生成接口 |
| 设置持久化 | 强制停止后重开，地址前缀、模型选择和自动开关状态仍保留 | 自动进入关闭、自动答题开启、自动提交关闭；保留用户已有设置 |
| 后台服务 | `dumpsys` 确认前台服务、不可清除的常驻通知及 PARTIAL_WAKE_LOCK；切到后台并熄屏后，约 40 秒后进程仍存活，返回应用正常 | 设备曾显示 Dozing，后续为 Awake；未证明持续深度休眠，也未测试后台真实课堂事件 |
| 界面 | 已查看长标题换行、卡片与图标、模型下拉和下载入口；多轮刷新未观察到周期顶部进度条 | 未做真机最大字号、横屏或全部页面覆盖；小屏及字号 1.5 另有离线布局测试 |
| 稳定性 | 页面切换、导出和重启正常；检查当前应用 PID 的系统 crash buffer 无输出 | 无长期运行或低内存压力测试 |

模型列表此前的 HTTP 404 对应手机保存的旧地址。使用用户确认的专属服务地址后，兼容端点 `/models` 已在真机成功返回模型列表，本轮无需为此修改请求实现。完整地址、密钥和账号信息不写入此文档。

## 仍需受控课堂验证

当时动态页显示“暂无正在上课的课堂”。以下项目尚未验证：

- 三种登录方式的完整登录与安全验证流程。
- 手动/自动入课、动态二维码、本节签到报告时机及位置签到确认。
- 进行中课堂的课件事件、远端本人答案同步和各题型提交。
- 固定内容和 AI 的自动填充、用户修改后提交、开启自动提交后的行为。
- AI 提示词、四种课件发送范围及实际生成结果。
- 锁屏期间收到真实课堂事件、断网重连、长时间运行和厂商省电限制。
- 官方客户端课程总数对照、归档和多页历史数据完整性。

本轮没有向雨课堂提交答案、签到或入课请求，没有调用 AI 生成，也没有向任何联系人或外部应用发送文件。最后保留自动提交关闭，设备停在课程页。
