# 1.1.2 测试记录

正式版本：1.1.2+21。用户已验收 build 20，并授权追加布置题目通知后直接构建发布。

## build 20 测试记录

- 后台事件通知复用各平台本地通知接口，课级通知允许没有题目 ID；前台不发送，同课堂/题目仅更新最新状态，避免周期重复提醒。
- 保留需要手动作答、确认提交及失败处理的原有题目提醒；新增入课、普通及位置签到结果、自动作答开始、草稿填充、提交结果及课堂结束事件。
- 倒计时由提交队列实际截止时间实时计算，不修改原提交时间。UI 回归覆盖 30→29→28 秒；队列仍满足布置后延迟与上一题成功提交后延迟中较晚的一项。
- 用户确认原先运行 1.1.1 build 18，该测试包仍含周期同步；正式 build 19 已取消。本轮真实运行 25/50/75 秒轮询回归，验证不会额外同步本人答案；同步日志标识 afterSubmission 或 manualRefresh。
- 自动签到确认增加“只会自动进入已加入的课堂，新课需要扫码加入”，关于页同时显示版本及 build。

全部 551 项 Flutter 测试通过，静态分析无问题。覆盖通知状态去重、前台抑制、同账号重登录及课堂结束时迟到回调撤销，以及原自动提交队列和逐秒 UI 显示。

## build 21 正式构建

追加教师布置题目的后台通知，按实际自动化设置显示提交安排；只有实际排队截止时间确定后显示提交秒数，未准备好或等待前题时显示相应状态。自动提交关闭则提示手动确认，不会误称自动提交。提交成功后清除布置通知并显示提交结果，题目相关通知统一按课件页码标识，例如“第 7 页题目”。

按用户要求，本轮不另行测试或设备验收，仅做代码审查、格式化、构建与安装包核对；现有通知测试的预期已随通知语义维护但未执行。Windows/iOS 手动构建关闭测试步骤，提交标记跳过自动 CI。安装包核对结果完成后补充。
