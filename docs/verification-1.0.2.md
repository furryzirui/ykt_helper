# 1.0.2 验收记录

版本：1.0.2+8；日期：2026-11-14；状态：待用户再次验收，不发布 Release。代码提交：`059cac5f131b31cd9b83dbf9f810382914521a15`。本次产物替代上一轮 1.0.2+7 验收包。

- 本地 297 项 Flutter 测试通过，静态分析无问题。本次新增 Windows 自启动授权前禁用、开启与保存前重新核验、授权撤销、读取异常、权限用途确认及开关动画状态不会复用到其他设置项的回归覆盖。
- Windows 用户确认后先注册当前用户启动项，再读取系统授权；无需管理员权限。权限注册与后台运行标志分离，关闭开关时保留可见启动项，后台启动入口在创建窗口和 Flutter 引擎前核验授权、应用开关及运行条件。不会覆写系统禁用状态。
- 原生自启动策略通过 47 项隔离注册表检查，测试进程重定向 HKCU 至专用临时键，未向本机真实启动列表注册应用。原生修改通过 MSVC `/W4 /WX`（沿用工程对未使用入口参数的排除）编译检查。
- 扫码测试覆盖扫描范围、双指变焦、相机控制、权限确认、生命周期、重复识别及销毁。上一轮已检查手机 360×800、横屏 800×400、字号 1.0 / 1.5、键盘和 Windows 离线截图；本轮补查自动化布局及开关位置。
- Android 两个正式签名 APK 均核对包名、1.0.2+8、最低 API 26、target API 36、独立发布证书、v2 签名、ZIP CRC 和实际架构；arm64 包仅包含 arm64-v8a，universal 包包含三种 ABI。
- 本次 [Windows / iOS CI](https://github.com/furryzirui/ykt_helper/actions/runs/43604711086) 与 [Android CI](https://github.com/furryzirui/ykt_helper/actions/runs/43604708168) 的完整构建均通过。Windows 原生授权检查也在 CI 中通过。
- 下载后核对 Windows 安装器的 PE、版本和 CI 载荷打包证据，未独立解包重算 EXE 内容。iOS IPA 的 1.0.2+8、arm64、主应用未签名、ZIP CRC、Ed25519 清单签名及全部 50 个受校验文件的摘要均通过核验。
