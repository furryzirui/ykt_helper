# 1.0.2 验收记录

版本：1.0.2+12；日期：2026-11-15；状态：用户验收通过；发布版本：1.0.2。代码提交：`7ca6a85dc9069a1d9d7c7349b250e672dd54c7f9`。本次产物替代上一轮 1.0.2+11 验收包。

- 346 项 Flutter 测试通过，静态分析无问题；Windows 自启动通过 81 项隔离注册表检查。测试使用专用临时键，没有修改本机真实启动项。
- Windows 自启动识别全零启用状态；未知格式允许开启，仅系统明确禁用时阻止开启。自动化页移除权限跳转按钮，权限页入口保留。
- 设置自动保存：开关和选项即时保存，文本停止编辑 600 毫秒后保存，返回前刷新待保存内容。校验不再阻止持久化，空地址、密钥、模型、提示词、答案及范围外的延迟均原样保存、重启恢复。测试覆盖快速连续修改、异步模型获取、返回页面和真实控制器持久化。
- 固定答案使用 A–D 单选及多选按钮，之后独立显示判断答案，默认“正确”。任意两个选项均按判断题处理，手动作答与自动答题保持一致；题目选项更新后会清除失效选择。固定填空为每个空重复填写完整内容，不再按行或分号拆分。
- 修复自动答题关闭后，隐藏的 AI 配置仍阻止签到和服务设置保存的问题。新增 Windows 界面与真实持久化回归，覆盖已有或不完整 AI 配置、模型请求中关闭答题及迟到结果；开启状态和配置可一起保存，不要求先完成配置。
- 右上角正常显示“已自动保存”，校验失败只显示原因；校验与写入结果独立。仅实际写入失败显示保存失败，可点击重试。模型等待不误报失败，无加载图标或页中横幅；状态变化不移动正文。已核对窄屏、横屏、宽屏和 1.5 倍字号截图。
- 系统自启动注册或后台服务执行失败独立反馈，不回滚已保存的本机设置。Windows 明确禁止自启动时的开关限制保持原规则。
- 应用自启动设置项保持常驻；Android 未启用自动启动服务时显示“请在启用自动启动服务后开启”。已检查手机及横屏布局、1.0 / 1.5 字号与固定答案选项截图。
