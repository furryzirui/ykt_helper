# 0.1.3

版本：0.1.3+4；日期：2026-11-14。

- 应用及仓库统一命名为 `ykt_helper`，Android 包名改为 `com.furryzirui.ykt_helper`，iOS Bundle ID 为 `com.furryzirui.ykt-helper`。Android 新包名与此前测试包不同，将作为独立应用安装；旧包的登录态和设置不会自动转移。
- 新保存的课件图片统一放入系统相册的 `Pictures/ykt_helper` 目录；历史已导出的文件仍由用户管理。
- 相机与通知先说明用途和操作步骤，确认后优先请求单项系统权限弹窗。系统无法再次弹窗、永久拒绝、旧系统通知或通知类别关闭时，再打开本应用的权限或通知设置。用户普通拒绝后不会立即强制跳转设置。
- 电池优化管理不再按当前授权状态跳转不同页面，统一进入本应用详情，由用户在“电池”或“耗电管理”中调整。状态仍读取 Android 标准电池优化豁免，不把它等同于厂商的全部后台限制。
- 登录方式改为二维码、验证码、账号密码三项并列。切换方式清空秘密输入并取消二维码轮次，迟到的二维码结果不能恢复旧界面。
- 设置首页改为账号、应用权限、自动化、应用日志、关于。自动签到、自动答题、自动提交及固定答案/AI 配置集中到“自动化”二级页面，保留明确保存和未保存草稿。
- 恢复本地应用日志，位于自动化入口下方。日志页右上角可导出 TXT 文档，通过系统分享面板保存或分享；最多保留最近 500 条事件，只记录预定义操作类型、结果和数字状态，不记录账号、凭证、模型地址、题目或答案。导出会等待历史日志读取完成，避免刚打开页面即导出时漏掉已有记录。
- 扫码进入课堂移至课程和动态页面右上角，与刷新并列，移除动态页正文中的大按钮。
- 课堂列表直接显示已签到、未签到或未同步。签到报告独立读取，限制同时请求数；报告不可用、读取失败及不支持的旧版课堂保持未同步，不根据入课成功推断。
- 设置最下方新增关于页，显示开发者“紫锐飞跃”、开源仓库和 GPL-3.0 许可，仓库链接可用外部浏览器打开。

仓库地址：<https://github.com/furryzirui/ykt_helper>。本轮不发布 GitHub Release。

本轮按用户要求不使用 ADB、不安装或操作手机。最终本地检查结果见 [验证记录](verification.md)；单项授权弹窗、厂商电池管理、真实签到报告及其他手机流程由用户按照 [Android 联调清单](android-validation.md) 自行验证。
