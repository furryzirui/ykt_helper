- 旧版课堂详情不再列入适配计划。
- 移除 User-Agent 设置及诊断日志，清理应用临时目录内旧诊断文件。
- AI 提示词可编辑，默认保持原提示；题目始终随请求发送，选课件时追加参考课件提示。

- 自动答题增加默认关闭的“自动提交”：关闭时固定答案和 AI 答案仅填充，由用户确认或修改后提交。
- 设置保存成功后才生效，迟到模型/答案结果不会跨账号或配置覆盖。
- 课程和课堂长标题完整换行；调整功能图标、卡片和状态显示。
- 课堂内显示本节签到状态，位置签到独立显示。
- 移除定时刷新的顶部进度条。
- 历史详情仅保留课堂回顾入口；移除重复课件入口和回放及播放器依赖，下载移入回顾内。

本轮 93 项本地测试通过，静态分析无问题。真实服务和后台运行仍按 Android 联调清单验收。
